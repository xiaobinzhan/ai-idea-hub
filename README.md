# 🧠 AI Idea Hub

> 每天刷到的 AI 应用灵感，经过提炼变成你的思考资产。

## 这是什么

一个结构化的 AI 应用灵感收藏夹。每当我看到有意思的 AI 工具、产品、案例或观点，都会提炼成结构化的条目存到这里。

## 目录结构

```
ai-idea-hub/
├── README.md                      # 项目总览
├── TEMPLATE.md                    # 条目模板
├── ideas/                         # 所有 idea 条目
│   ├── _index.md                  # 按分类/时间汇总的索引表
│   ├── llm-apps/                  # LLM 应用（ChatBot、RAG、Agent…）
│   ├── ai-coding/                 # AI 编程（Cursor、Copilot、Codex…）
│   ├── ai-media/                  # AI 多模态（文生图、视频、音频…）
│   ├── ai-workflow/               # AI 自动化与工作流
│   ├── ai-industry/               # 行业 AI 应用（金融、医疗、教育…）
│   └── ai-thoughts/               # 观点、趋势、深度思考
└── archives/                      # 原始资料备份（可选）
```

## 分类说明

| 分类 | 说明 |
|------|------|
| `llm-apps` | LLM 驱动的应用，如对话机器人、RAG 系统、Agent |
| `ai-coding` | AI 编程工具、编码助手、自动化开发 |
| `ai-media` | 多模态 AI，包括文生图/视频/音频/3D |
| `ai-workflow` | AI 自动化流程、工作流编排、智能体协作 |
| `ai-industry` | 行业垂直 AI 应用（金融、医疗、教育、法律等）|
| `ai-thoughts` | 趋势分析、观点文章、深度思考 |

## 标签体系

每条 idea 会打标签，便于交叉检索。常用标签：

- `#agent` `#rag` `#multimodal` `#coding` `#automation` — 技术类
- `#product` `#tool` `#framework` `#opensource` — 形态类
- `#finance` `#healthcare` `#education` `#creative` — 行业类
- `#trend` `#opinion` `#prediction` — 观点类

## 评分标准

每条 idea 标注两个评分（1-5）：

- ⭐ **兴奋度**：这个 idea 有多让我兴奋
- 🎯 **可落地性**：这个 idea 有多容易落地或借鉴

## 使用方式

看到好东西 → 把链接/截图/描述丢给我 → 我提炼归档 → push 到仓库
