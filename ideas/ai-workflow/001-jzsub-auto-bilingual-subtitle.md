# JZSub —— 自动下载视频并烧录双语字幕的 AI Skill

## 💡 Idea 提炼

- **核心思路**：将「视频下载 → 大模型上下文对照翻译 → 字幕烧录」串成一条龙的 AI Skill，自动给任意视频生成对照双语字幕并封装进画面。
- **关键亮点**：
  - 支持 YouTube 等 **1000+ 视频网站** 的视频源
  - 下载最佳画质视频与音频，封装为 MP4
  - 用大模型做**上下文对照翻译**（术语/语气一致，优于逐句机械翻译），字幕直接**烧录**进视频，无需播放器加载字幕文件
  - 可运行在 Codex、Claude、国内 WorkBuddy 等多种 Agent 环境，作为可复用 Skill 即调即用
- **技术要点**：基于视频下载器（yt-dlp 类）封装 + 大模型翻译 + 字幕烧录（ffmpeg 类），整体走 Agent/Skill 编排范式；价值在「端到端自动化流水线」而非单一模型能力。

## 📝 我的思考

- 这是一个典型的「Vibe Work」范式：把繁琐的媒体处理（下载+翻译+烧录）封装成一个 Agent 可直接调用的 Skill，普通人用自然语言就能跑通专业流水线。
- **可迁移方向**：
  - 可借鉴其「下载→翻译→烧录」模式，扩展到课程/播客/教学视频的本地化
  - 若用户丢来视频链接，可设想类似能力：自动产出带双语字幕的版本
  - 上下文对照翻译的思路（保持前后术语一致）值得在长文档/长视频翻译场景中复用
